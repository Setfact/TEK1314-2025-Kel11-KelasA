| Ta# Attack Plan – Simulasi SOC Kelompok 16 (KABITA Smart Breeder)

| Tahap | Skenario | Teknik & Tools | Target Node | Hasil yang Diharapkan |
|---|---|---|---|---|
| 1 | Brute Force Testing (PostgreSQL & Login) | Pengujian brute force pada endpoint login dan koneksi lokal PostgreSQL dari akun SSH non-privilege (Hydra / wordlist / klien PostgreSQL) | PostgreSQL (`127.0.0.1:5432`) & Endpoint Login ThingsBoard (Nginx) | Memastikan percobaan autentikasi berulang ditolak (Rate Limiting HTTP 503 / SCRAM-SHA-256), akses dibatasi PoLP, dan aktivitas tercatat di log host serta Security Onion. |
| 2 | Analisis Paket HTTP Tidak Terenkripsi | Penyadapan (*sniffing*) lalu lintas jaringan lokal menggunakan Wireshark / `tcpdump` terhadap trafik web monitoring | Jalur komunikasi web monitoring ThingsBoard (HTTP port 80/8080 ke HTTPS port 443) | Mengidentifikasi apakah kredensial dan payload telemetri terbaca dalam bentuk *plaintext*, serta memverifikasi enkripsi penuh melalui HTTPS/TLS setelah mitigasi. |
| 3 | Exploitation / Akses Dashboard & API | Pengujian kontrol akses, autentikasi, dan endpoint REST API menggunakan Browser dan OWASP ZAP, serta uji eskalasi lokal dari akun SSH non-privilege | Dashboard IoT ThingsBoard, REST API, & Target Node (Debian 13) | Mengidentifikasi kelemahan autentikasi/otorisasi tanpa mengubah data produksi, serta memastikan akses ilegal dan eskalasi lokal ditolak dan tercatat oleh `auditd`/Security Onion. |
| 4 | Web/API/Protokol IoT – MQTT Unauthorized Access | Percobaan *publish*/*subscribe* tanpa autentikasi (*access token*) menggunakan MQTT Explorer atau Mosquitto client (`mosquitto_pub`) | MQTT Broker ThingsBoard (port `1883/tcp`) | Memastikan broker menolak klien yang tidak memiliki *access token* sah dan mencatat aktivitas mencurigakan di log ThingsBoard serta Security Onion. |
| 5 | Security Misconfiguration (Nginx, HTTPS & Header) | Pemeriksaan *banner grabbing* dan kelengkapan header keamanan HTTP menggunakan OWASP ZAP dan `curl -I` | Web Server / Reverse Proxy Nginx (port 80/443) | Mengidentifikasi eksposur versi server (`nginx/1.26.3`) dan ketiadaan header pertahanan, serta memverifikasi banner tersamar (`Server: nginx`) dan 5 header keamanan OWASP aktif. |
| 6 | DDoS Resilience Testing (Availability) | Simulasi lonjakan beban HTTP terkendali menggunakan `k6` (atau skrip *load testing*) menuju Nginx dan endpoint API | Nginx Reverse Proxy & Endpoint API ThingsBoard | Menguji ketahanan ketersediaan layanan serta memverifikasi *Leaky-Bucket Rate Limiting* Nginx (HTTP 503 untuk *request* berlebih) dan proteksi kernel SYN Cookies bekerja. |
