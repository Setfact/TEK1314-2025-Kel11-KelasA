\# Deklarasi Tech Stack - Proyek Sistem Monitoring \& IoT



| Layer / Komponen | Teknologi yang Digunakan | Keterangan / Peran |

| :--- | :--- | :--- |

| \*\*Operating System\*\* | Debian 13 (Trixie) | Server host utama untuk deployment aplikasi dan monitoring |

| \*\*Frontend\*\* | React.js + TypeScript | Antarmuka pengguna (UI/Dashboard) berbasis komponen modular dan type-safe |

| \*\*Backend \& BaaS\*\* | Supabase / Supabase Edge Functions | Layanan backend terkelola (Autentikasi, REST API otomatis, dan Realtime Webhook) |

| \*\*Database\*\* | PostgreSQL (Managed by Supabase) | Basis data relasional utama untuk penyimpanan data pengguna dan telemetri |

| \*\*Web Server / Reverse Proxy\*\*| Nginx | Reverse proxy, static file server, dan SSL/TLS termination di Debian 13 |
